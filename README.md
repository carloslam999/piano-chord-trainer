# Nocturne Op. 9 No. 2 Chord Trainer

A play-along page for learning Chopin's Nocturne in E♭ major, Op. 9 No. 2 from chords: falling melody and chord notes on a piano, a bar-by-bar chord map, looping and adjustable speed. Open `index.html` in any browser.

Chord symbols follow the bar-by-bar table at chopinlefthand.com. Melody and left-hand note data come from the public-domain G. Schirmer 1881 edition as typeset by the Mutopia Project (Renato Biolcati Rinaldi), licensed CC BY-SA 3.0; this page shares that data under the same license.
